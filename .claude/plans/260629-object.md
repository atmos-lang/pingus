# Plan: Object as the single event source (id-carrying)

Collapse the per-caller `:Button` event into the `Object`'s own
`:o.*` events, which now carry a caller-supplied `id`.
Callers stop defining new events; they filter `:o.* [id=me]`.

## Motivation

Today the chain is:

```
Object --:o.* @parent--> Button --:Button [id] @target--> dispatcher
```

`Button` re-defines an event (`:Button`) just to relabel a click.
Instead, let `Object` tag every event with the caller `id` and emit
straight to the dispatcher; everyone filters by `id`.

```
Object --:o.* [id,obj] @tgt--> (broadcast to tgt subtree)
        |                         |
        Button (hover [id=me])    dispatcher (click [id])
```

## Verified mechanism

`emit @N :o [id]` is rooted N levels up and **broadcasts through that
subtree** -- every awaiting task there sees it and filters by `id`
(`scratchpad/bcast.atm`: two sibling listeners both saw one emit).
So one emit to the dispatcher reaches the dispatcher (for clicks) and
every sibling `Button` (for its own hover).

## Object (new)

`task Object (id, rect, tgt)`

- `id` -- anything from the caller (e.g. `:Leave`, `:Open`, `:quit`).
- `pub` gains `id`: `[id, rect, over, left, right, middle]`.
- every emit carries it:
  `emit @(tgt) [tag=..., id=id, obj=pub]`
  (tags unchanged: `:o.over.on/off`, `:o.click.dn/up`).
- `tgt` is the dispatcher (see decisions); the motion/button `par`
  and the `until pub.over` guard are unchanged.

## Button (new)

`task Button (id, tgt, style, text, rect)`

- passes `id`, `tgt` to `Object`; no longer re-emits `:Button`.
- the second `par` branch (click -> `:Button`) is removed.
- hover/highlight/tick now filter to this button:

```
loop {
    await :o.over.on [id=id]
    pico.output.sound(style.sound)
    toggle hl(true)
    await :o.over.off [id=id]
    toggle hl(false)
}
```

## Dispatchers

Replace `await :Button` + `match but.id` with the `Object` click:

```
loop {
    val e = await :o.click.dn
    match e.id {
        :Leave  => break()
        :Open   => ...
        :Locked => ...
    }
}
```

- `menu.atm` `task ()`  -- `:Story/:Editor/:Levels/:Options/:Exit`.
- `story/world.atm` `World` -- `:Leave` + dot `:Open`/`:Locked`.

## Decisions / open

- **`tgt` value.** DECIDED: numeric levels, `Button` adds `+1`.
  `Object` sits exactly one level below `Button`, so forwarding
  `target+1` makes `Object`'s emit root at the *same* place the old
  `:Button` emit did -- every call site stays unchanged.
- **filter syntax.** `await :o.over.on [id=id]` (event-payload filter)
  is valid atmos -- used as-is.
- **Hover fan-out.** Every `Object` now broadcasts hover to the whole
  dispatcher subtree, so each of N buttons filters N over-events
  (N^2). Fine for menus/worldmap; note if a screen ever has many.
- **`:o` payload.** Consumers read `e.id` + `e.obj` (the `pub`); the
  highlight could even read `obj.over` instead of on/off events --
  out of scope for now.
